**Autora**: Midiã Lins  

Projeto desenvolvido para a disciplina de sistemas operacionais, com exercícios práticos em Python.

Os exercícios envolvem conceitos básicos como:
- entrada de dados;
- uso de variáveis;
- operações matemáticas;
- conversão de tipos;
- exibição de resultados.

Os enunciados dos exercícios estão disponíveis no arquivo correspondente do projeto.
